## Shared runner boundary and signature rules

Proposed factory interface in `tests/support/contract_doubles.py`: `checked_agent_runner(script: object) -> AgentRunner`. It returns `create_autospec(AgentRunner, instance=True, spec_set=True)` and delegates the synchronous .run call to the scenario's current .run implementation. Do not instantiate a real AgentRunner or add a handwritten production-like Protocol. Missing/noncallable run is an explicit fixture-construction TypeError. Reject real AgentRunner instances/subclasses and existing Mock/NonCallableMock (including an already-checked boundary) before inspecting script behavior. This forbids double wrapping and guarantees explicit opt-in. Central make_adapter/_adapter/script helpers take scripted observers only; callers needing a real runner use direct adapter construction or an explicit real_runner= keyword branch which passes the real object through, never type-sniffing inside the autospec factory. Preserve the helper tuple's original observer return; assertions read it rather than adapter._runner. Keep the script as the observer; do not copy lists or turn mock children into values. Do not automatically wrap an already real AgentRunner or real subclass; sites explicitly opt in for a scripted double, and actual-runner paths stay real.

Pinned consumer audit: JsonRpcDispatcher and AgentGoldenTaskHarness call only run; AcpDuplexAdapter also probes _planning_progress_observer; AcpStreamServer reads getattr(agent_runner, "event_sink", None). Bootstrap constructs real runners. No injected-runner isinstance branch was found in those pinned consumers. Pin checked.event_sink=None for the named scripts (they had no sink), preserve the pre-conversion absence of _planning_progress_observer, and bind any newly discovered consumed member to its actual prior meaning at Task1. _model and _gateway_client are constructor-only fields, not automatically present in an AgentRunner class autospec: do not fabricate them to match a reviewer's conditional example. Every actual non-dunder callable member other than run gets a recording-and-failing default. Actual adapter/dispatcher/server controls must show zero unexpected member calls and the audited optional-member semantics; static source inventory supplies the member-read proof without building a __getattribute__ proxy framework.

The actual run is synchronous: required request followed by ten keyword-only planning_progress_observer, client_mcp_service, mcp_permission_broker, halt_requested, operation_control, context_packer, stage_receipts, route_binder, integrity_failure and recovery_checkin, each defaulting to None. Derive enforcement/introspection from the actual class, not this copied description. The mock boundary must expose this signature. Reject a missing request, extra positional argument or obsolete keyword before the script runs, and reject unknown attribute assignment.

Narrow scripted run methods must accept the now-visible real optional kwargs. Add `**runtime_kwargs` only behind the checked real boundary, retaining each currently consumed explicit parameter and its behavior. Do not filter/drop kwargs using inspect.signature(script.run), duplicate `_runner_runtime_kwargs`, change production introspection, replace callbacks with no-ops, or silently catch TypeError.
